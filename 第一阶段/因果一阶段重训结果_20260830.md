# 因果一阶段重训结果（2026-08-30）

本文件记录严格“仅使用过去动态观测”的一阶段重训。它用于验证 PS、WPS、TS、Tm 的因果特征管线，不是二阶段独立 GNSS-PWV 的最终精度。

## 统一实验协议

- 数据：2014–2018 年的 profile 重建数据，363 个可读取的 `*_met.txt` 文件。
- 留站点：随机种子 42，约 10% 的站点（35 个）完全留出；这些站点在 2014–2018 年的全部序列只进入留站点验证。
- 其余站点：2014–2016 训练，2017 测试，2018 验证。
- 特征：静态时空特征与 PS/WPS/TS/Tm 的 `t-1` 及更早滞后、差分和滚动特征；滚动统计均在 `shift(1)` 后计算。禁止在预测时刻使用任一动态变量当前值。
- 缩放：仅用训练索引拟合（PS 作业启动于保存缩放器/年份统计改动之前，见下文产物完整性）。
- 模型：2 层 GRU（hidden=128），30 epochs，NVIDIA L40；评估采用 2048 条分批推理以避免全量验证集显存溢出。

## 汇报时必须保留的边界

1. PS/WPS 的误差单位为 hPa，TS/Tm 为 K；不同变量的 RMSE、MAE 和 R²不能视作同一排行榜。
2. 2018 仅检验非留站点的时间外推；留站点检验未见站点的空间外推，并含 2014–2018 年。两类验证不可合并或择优报告。
3. 数百万 N 是重叠滑动窗口数，不等同于数百万独立气象样本。
4. 一阶段特征“过去可用”只证明代码不读取同刻动态观测；真正业务部署还需验证历史观测的到达时效、缺测和数据质量。
5. 没有独立 GNSS ZTD/ZWD 和独立 PWV 标签前，不得将本文件中的任何误差描述为最终 GNSS-PWV 或二阶段独立精度。
