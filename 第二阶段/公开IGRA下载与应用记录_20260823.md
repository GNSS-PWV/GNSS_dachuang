## 字段可用性

IGRA derived 层记录包含：

- pressure；
- reported geopotential height；
- temperature；
- vapor pressure；
- header 中地表到 500 hPa 的 precipitable water `PW`。

它可以重建二阶段的部分层输入：`ELV、TS、PS、WPS`。但 `PW` 只覆盖地表到 500 hPa，不能直接作为项目完整 `PWV` 标签；IGRA derived 也不直接提供 `ZWD/ZHD/ZTD`。

## 已新增工具

```text
第二阶段/igra_public_profile.py
```

功能：

1. 使用 curl 断点续传下载单站公开 IGRA derived 文件；
2. 解析固定宽度层记录；
3. 输出 `station_id、TIME、PRESSURE_HPA、ELV_M、TEMP_K、VAPOR_PRESSURE_HPA` 中间 CSV；
4. 明确标记 `ZWD/PWV` 尚未生成，避免伪造标签。

另新增实验性重建工具：

```text
第二阶段/igra_reconstruct_profile.py
```

它可用气压积分重建整层 PWV，并用物理 Tm 关系重建 ZWD，输出与现有 `data.py` 相容的字段。但该输出只能用于数据链路和格式验证，不能直接作为老师要求的正式训练数据，直到与 ERA5/老师标签交叉验证。

下载并解析示例：

```powershell
python .\第二阶段\igra_public_profile.py download `
  --station AEM00041217 `
  --output-dir .\第二阶段\公开IGRA

python .\第二阶段\igra_public_profile.py parse `
  --zip-dir .\第二阶段\公开IGRA `
  --station AEM00041217 `
  --output-dir .\第二阶段\公开IGRA中间数据
```

## 单站应用结果

已完成 AEM00041217 的完整单站探针：

- 下载压缩包：50,692,564 bytes，ZIP 完整性检查通过；
- 解析：26,151 条廓线、470,884 个层记录；
- 重建实验：2014–2019 共 4,192 条廓线、63,456 个层记录；
- 输出：`第二阶段/公开IGRA重建兼容输入_20260823/AEM00041217_met.txt`。

该输出通过字段预检，但因只有一个站点，严格切分时没有训练站，不能训练模型；它仅用于验证下载、解析、积分标签接口和字段格式。

与本地已有同站 2014 数据的 672 条共有廓线比较：

| 字段 | 重建结果与已有结果差异 |
|---|---:|
| PWV RMSE | 2.09 mm |
| Tm RMSE | 3.21 K |
| TS RMSE | 0.036 K |
| PS RMSE | 1.253 hPa |
| WPS RMSE | 0.000 hPa |

这证明公开 IGRA 层字段与项目层输入基本相容，但 PWV/Tm 标签仍有明显口径差异；正式训练前必须用 ERA5 或老师提供的原始标签进行校准。
