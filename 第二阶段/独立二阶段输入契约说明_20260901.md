# Independent Phase-Two Input Contract

## Purpose

This contract is the mandatory gate before a new phase-two GPU training run.
It prevents three known invalid paths: radiosonde-derived true ZWD as input,
profile/PWV closed-loop labels, and target-time information in a phase-one
profile. Historical `*_met.txt` reconstruction files cannot be passed to this
gate as formal phase-two data.

## Contract row

Use one CSV or Parquet row per `(station_id, analysis_time_utc)` and satisfy
the columns in `phase2_independent_contract_schema.json`.

- GNSS chain: `ztd_gnss_mm - zhd_model_mm = zwd_gnss_mm` within 0.01 mm,
  with GNSS source/epoch IDs and an availability time at or before analysis.
- Phase-one chain: a CSV profile referenced by SHA-256. It may contain only
  `ELV, TS, PS, WPS` for dynamic layers, must be marked `phase1_causal`, and
  its maximum observation time must be strictly before analysis time.
- Label chain: an independently sourced `pwv_label_mm`, its match time,
  source/epoch IDs, and a lineage root distinct from the input lineage root.
- Split: the accepted values are `train`, `test_2017`, `val_2018`,
  `val_leave_station`, and `val_2019`; membership is checked against the
  strict split manifest and analysis year.

`label_available_at_utc` is retained for provenance but is never used to
qualify a real-time input. Labels are supervision/evaluation only.

## Run

```powershell
python .\第二阶段\preflight_independent_phase2_inputs.py `
  --contract .\phase2_contract.csv `
  --split-manifest .\strict_split_manifest.json `
  --profile-root .\phase1_profiles `
  --out-dir .\phase2_preflight
```

The command writes `preflight_report.json` and `preflight_rejections.csv`.
Any rejection returns a nonzero exit code. A training launcher must verify a
passing report and the matching contract SHA-256 before calling a GPU job.

## Current Boundary

The current causal phase-one reruns establish a past-only feature pipeline.
They do not by themselves create the independent GNSS ZTD, ZHD, PWV label, or
profile-matching datasets required by this contract. Therefore the next
phase-two training has not been submitted.
