# 严格 profile 级重训准备说明（2026-08-22）

## 目的

在不改变旧训练入口和旧结果的前提下，预先完成老师最新数据协议的训练入口、切分和数据闭环检查。完整垂直廓线数据到位后，可直接在同济超算执行正式重训。

## 新入口

```text
第二阶段/strict_profile_preflight.py
第二阶段/strict_train.py
```

正式训练示例：

```bash
python strict_train.py \
  --data_dir /path/to/profile/2014_2018 \
  --data_dir /path/to/profile/2019 \
  --output_dir result_strict_train_20260822 \
  --require_all_splits
```

如果 2014–2019 位于同一个递归目录，也可以只传一个 `--data_dir`。

## 协议保证

- 2014–2018 站点全集确定留站点；
- 留站点全部年份进入 `val_leave_station`；
- 剩余站点按 2014–2016 / 2017 / 2018 划分；
- 2019 进入 `val_2019`，不参与训练和早停；
- `ProfileDataset` 的 level/global/height scaler 只由 `train` 拟合；
- 训练结束后分别输出 `test_2017`、`val_2018`、`val_leave_station`、`val_2019` 指标与预测明细；
- 旧版 `train.py` 继续保留旧协议，不会被静默改变。

## 当前可做与当前依赖

目前无需老师新文件即可完成：代码入口、字段检查、切分规则、Scaler 隔离、输出结构和超算命令准备。正式运行仍依赖完整 `*_met.txt` profile，至少包含：

```text
TIME,YEAR,DOY,LAT,LON,ELV,TS,PS,WPS,ZWD,ZHD,ZTD,PWV
```

`Tm` 可选，仅用于诊断和传统基线对比；EC 数据不影响这一步基础重训入口。
