# GNSS_dachuang：基于深度学习的两步法实时 GNSS 水汽反演

本仓库是项目的**代码、文档与可复现流程发布快照**。它覆盖：

- `第一阶段/`：Ts、Tm、PS、WPS 等辅助气象参数建模代码；
- `第二阶段/`：ProfileTransformer、严格站点/年份切分、训练、评估、审计与 IGRA profile 重建工具；
- `数据计算代码/`：GNSS、ERA5 下载与 ERA5 积分流程代码；
- `通用框架_CCFA/`：通用框架实验代码；
- 根目录 Markdown：研究设计、数据口径、交接、预检和结果解释文档。

## 数据策略

为避免 GitHub 大文件限制、公开传播数据及复现混乱，本仓库**不包含**原始观测、IGRA ZIP、重建 profile、ERA5/EC 文件、CSV、NetCDF、模型权重、PPT、训练输出或认证信息。

训练机器应先拉取本仓库，再按 [`docs/SERVER_DATA_UPLOAD.md`](docs/SERVER_DATA_UPLOAD.md) 上传冻结数据到相同目录布局。训练数据不得直接提交回 GitHub。

## 第二阶段严格协议

- 使用 2014--2018 年作为核心数据；2019 年为独立最终验证；
- 从实际拥有有效 2014--2018 profile 的站点中，以 `seed=42` 留出 `floor(10%)` 站点；
- 留站点全部年份进入留站验证；其余站点：2014--2016 训练、2017 测试、2018 验证；
- Scaler 只在训练集拟合；
- 训练入口：`第二阶段/strict_train.py`。

详细口径请见根目录的项目交接/严格切分文档，以及 `第二阶段/严格profile级重训准备说明_20260822.md`。

## 使用边界

1. 不读取、提交或回显任何认证文件、密码、Token、私钥或 ERA5/UCAR 密钥；
2. 正式训练须在超算 GPU 分区通过调度系统提交，不能在登录节点运行；
3. 请先进行小规模 dry-run，再启动全量训练与五集合评估。
